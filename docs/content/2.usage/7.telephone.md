title: Installer sur téléphone
description: Rocket Clean comme une application sur Android et iPhone, utilisable hors ligne sur la page d’un ménage.

Rocket Clean est une **application web installable** (PWA) : une icône sur l’écran d’accueil, plein écran, sans passer par un store.

## Installer

- **Android (Chrome, Edge, Samsung Internet)** : bouton **Installer l’application** (page *Ménages du jour* ou page d’un ménage), ou menu ⋮ › *Installer l’application*.
- **iPhone / iPad (Safari)** : touche **Partager** › **Sur l’écran d’accueil** › *Ajouter*. Le bouton **Installer l’application** rappelle ces étapes.

Installée depuis **Ménages du jour**, l’application s’ouvre sur `/menage` (compte requis). Installée depuis un **lien secret** `/m/<jeton>`, elle rouvre **ce ménage**, sans compte. Raccourci (appui long sur l’icône, Android) : *Ménages du jour*.

L’installation demande HTTPS (ou `localhost`).

## Hors ligne

- La **page d’un ménage** (lien secret) garde sur le téléphone ses dernières données (7 jours) : sans réseau elle s’affiche avec un badge **Hors ligne**.
- Statut, points de checklist, niveaux de stock et notes modifiés hors ligne sont **mis en file** et envoyés dans l’ordre au retour du réseau (chaque envoi fixe une valeur : le rejouer ne change rien). Les **photos** demandent le réseau.
- Les pages avec compte (*Ménages du jour*, lieux) ne sont pas gardées hors ligne : aucune réponse authentifiée n’est mise en cache.

## Mises à jour

Une nouvelle version déployée affiche **Nouvelle version disponible** › *Recharger*. Le service worker (`/sw.js`) n’est actif qu’en production ; `NUXT_PUBLIC_PWA=false` le désactive (et le désinscrit des téléphones).

## Une vraie application Android (APK) plus tard

Le manifeste (`/manifest.webmanifest`) suffit à [PWABuilder](https://www.pwabuilder.com) ou à Bubblewrap (`bubblewrap init --manifest https://<domaine>/manifest.webmanifest`) pour produire une application Android (Trusted Web Activity), à signer puis à relier au domaine par `/.well-known/assetlinks.json`.
