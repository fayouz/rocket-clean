```bash
docker compose -f compose.yaml -f compose.demo.yaml up -d --build
```

Ou sur GitHub : **Code → Codespaces → Create codespace** (rien à installer, voir `demo/README.md`).

| Compte | Mot de passe |
|---|---|
| `alice@example.org` (gestionnaire) | `demo-alice-password` |
| `admin@example.org` (administrateur) | `demo-admin-password` |

La démo contient deux lieux locaux (« Le port » et « Les vignes », mêmes identifiants que la démo de Rocket Place), leur checklist et deux ménages (aujourd'hui, et un en retard) attribués à Alice. Ni Rocket Place, ni Rocket Cloud, ni Rocket Mailer : aucun e-mail ne part.

## Scénario conseillé

1. **Lieux → Le port** (admin) : planifier un ménage pour Alice, copier son **lien sans compte** et l'ouvrir dans une fenêtre privée.
2. Menu **Ménages du jour** (en Alice, sur téléphone) : commencer, cocher, photographier, terminer.
3. **Tableau de bord** : ménages du jour, terminés, en retard.
