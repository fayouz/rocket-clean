## Docker Compose

```bash
docker compose up -d --build
```

- Application : http://localhost:4000 (la configuration initiale crée le compte administrateur)
- API et documentation OpenAPI : http://localhost:9000/api/docs

## Développement sans Docker

```bash
# backend (PHP 8.4, PostgreSQL)
cd backend && composer install
php bin/console lexik:jwt:generate-keypair
php bin/console doctrine:migrations:migrate
php bin/console app:demo:seed            # avec DEMO_MODE=1 : lieux et ménages de démo
php -S 127.0.0.1:9000 -t public

# frontend
cd frontend && npm install && npm run dev -- --port 4000
```

## Intégrations

Les jetons des intégrations sont gardés chiffrés dans le **coffre des secrets** (Administration → Secrets), jamais dans le `.env` : générer la clé maîtresse avec `php bin/console rocket:secrets:generate-key` et la mettre dans `ROCKET_SECRETS_KEY` (`.env.local`). Une instance qui avait encore `ROCKET_PLACE_TOKEN` / `ROCKET_STOCK_TOKEN` / `ROCKET_CLOUD_TOKEN` / `ROCKET_MAILER_TOKEN` les importe avec `php bin/console app:secrets:migrate-env` (idempotent), puis retire ces variables.

- `ROCKET_PLACE_URL` + secret `rocket.place.token` (`rpl_…`) : lieux (et stock si Rocket Stock n'est pas configuré) de Rocket Place ; vide : lieux locaux (mode autonome).
- `ROCKET_STOCK_URL` + secret `rocket.stock.token` (`rst_…`) : stock de Rocket Stock ; chaque relevé pendant un ménage y enregistre une consommation puis l'état du niveau.
- `ROCKET_CLOUD_URL` + secret `rocket.cloud.token` (`rca_…`) : photos dans Rocket Cloud ; vide : démo.
- `ROCKET_MAILER_URL` + secret `rocket.mailer.token` (+ `ROCKET_MAILER_MAILBOX`, `ROCKET_MAILER_SENDER`) : e-mails ; vide : démo.
- `ROCKET_CLOUD_URL` + secret `rocket.cloud.token` : documents et photos de ménage dans Rocket Cloud.
- `ROCKET_MAILER_URL`, secret `rocket.mailer.token`, `ROCKET_MAILER_MAILBOX`, `ROCKET_MAILER_SENDER` : e-mails de ménage via Rocket Mailer (voir [Ménage](/usage/menage)).
- Le worker (`php bin/console messenger:consume async scheduler_default`) lance les tâches récurrentes (santé des services, e-mails quotidiens).

En mode suite (`ROCKET_AUTH_URL` + `ROCKET_AUTH_CLIENT_SECRET`), Rocket Cloud et Rocket Mailer sont appelés avec des jetons Rocket Auth ; les jetons statiques servent de repli.
